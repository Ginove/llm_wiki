## 远程桌面部署方案

### 架构
- Ubuntu 服务器：安装 XFCE 轻量桌面 + X2Go Server + LLM Wiki (.deb 预编译包)
- Windows：X2Go Client 连接，完整 GUI 操作
- API Server (`:19828`) 同时可选从 Windows 浏览器直连

### 步骤
1. Ubuntu 安装系统依赖（WebKitGTK 等 Tauri 运行时）
2. 安装 XFCE4 桌面 + X2Go Server（高性能远程桌面）
3. 下载 `LLM.Wiki_0.6.5_amd64.deb` 并安装
4. 配置 `LLM_WIKI_BIND_HOST=0.0.0.0` 放开 API 监听
5. 在服务器启动 `llm-wiki`
6. Windows 安装 X2Go Client，配置连接即可操作

### 效果
- Windows 内存只消耗 X2Go 客户端（~50MB），计算全部在 Ubuntu 上
- 完整 UI 体验（三栏布局、知识图谱、聊天、设置等）
- X2Go 比 VNC 快 2-3 倍，局域网内近乎本地体验
- API :19828 也可以从 Windows 浏览器直连
